# Health Pathfinder

A responsive TypeScript health-pattern assessment prototype designed as a calm, accessible decision flow.

It demonstrates:

- TypeScript with strict type checking
- State-driven multi-step assessment flow
- Responsive interface design
- Accessible button and progress interactions
- Clear, non-diagnostic results language

## Run locally

```bash
npm install
npm run build
```

Open `dist/index.html` in a browser.

## Notes

This is a portfolio prototype only. It does not collect personal information and does not provide medical advice, assessment, or diagnosis.
